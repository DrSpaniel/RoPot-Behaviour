# RoPot Behaviour
 Behaviour code for final project 'RoPot'.

This final project is a robotic plant monitor that constantly monitors the humidity/moisture level of plants to determine when the user should water their plant. The RoPot contains a custom made PCB, an LED matrix face, a speaker, motors, and a capacative soil sensor. The user can access it's plants humidity/moisture data via the RoPot web server or visually by observing the RoPot's emotions ( ex: smiley = hydrated, sad face= time to water). The RoPot also speaks when watering is needed such as "I am hungry, please water me", bang on the surface it lays on with it's arms if the user consistently ignores the plants cues, and of course 'die' (display: x_x ) if the user refuses to water the plant for a long time. The enclosure is fully modeled, and 3d printed by us! (ingredients will be added soon) this was made using arduino! thanks arduino.
