# RoPot Behaviour
 Behaviour code for final project 'RoPot'.

Tired of your plants dying from over or underwatering? Can't remember to water your plants? The RoPot is robotic plant monitor that constantly monitors the humidity/moisture level of plants to determine when you should water them! The RoPot contains a custom made PCB, an LED matrix face, a speaker, motors, and a capacative soil sensor. The user can access it's plants humidity/moisture data via the RoPot web server or visually by observing the RoPot's emotions ( ex: smiley = hydrated, sad face= time to water). The RoPot also speaks when watering is needed such as "I am hungry, please water me", use its arms to bang on a table with !!rage!! if the user consistently ignores the plants cues, and of course 'die' if it has been ignored for a long time. The enclosure is fully modeled, and 3d printed by us! (ingredients will be added soon) this was made using arduino! thanks arduino !
